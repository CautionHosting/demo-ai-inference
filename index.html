Demo: Verifiable AI Inference

Type a message to interact with the verifiable LLM.

Powered by llama.cpp. Phi-3.1-mini (3.8B).

What is this?

This is a demo AI inference application running inside a secure enclave. Your conversation is end-to-end encrypted and only decryptable by you and the enclave.

The main differentiators versus other confidential compute:

• verifiability

• true end-to-end encryption.

This agent runs on CPU which means it runs slowly. GPU support is in active development.

This software is currently in alpha and not production ready.
